# اللسان العماني — LisanOmani

منصة عمانية للسان واللهجة والمثل: معجم للمفردات اللهجية، وخريطة للمناطق،
ومدونة أمثال، ومساعد يجيب من بيانات المنصة.

موقع ثابت (Static Site) يعمل في المتصفح دون خادم أو قاعدة بيانات.

## الموقع

- **الرابط:** https://qmsweb.github.io/LisanOmani/
- **المستودع:** https://github.com/qmsweb/LisanOmani

## حالة الإصدار

الموقع **نسخة مراجعة غير مفهرسة**: يمنع الزحف عبر `robots.txt` ووسوم
`noindex` في كل صفحة، ولا يوجد ملف `sitemap.xml`. عند الإطلاق العلني تُزال
هذه القيود.

## الأقسام

- **المعجم اللهجي:** مفردات عمانية بمعانيها وشواهدها ومناطق تداولها، مع بحث وتصفية بحسب المنطقة.
- **الخريطة:** خريطة تفاعلية (Leaflet) لمناطق عُمان، مع توصيف موجز لكل منطقة وقائمة جانبية.
- **الأمثال:** أمثال متداولة في عمان والخليج، بمعانيها وموضوعاتها، مع بحث.
- **المساعد الذكي:** محادثة تجيب عن معنى مفردة، أو أمثال في موضوع، أو تعريف بمنطقة، اعتمادًا على بيانات المنصة داخل المتصفح.
- **عن المشروع:** الرؤية، نطاق المحتوى، فريق العمل، والبنية التقنية.
- **اتصل بنا:** نموذج يفتح بريد المستخدم موجّهًا إلى `me@jassim.one`، مع خيار نسخ الرسالة.

## تشغيل الموقع محليًا

بعض المتصفحات تمنع تحميل JSON عبر `file://`، لذا يُفضّل خادم محلي:

```bash
python -m http.server 8080
```

ثم افتح: `http://localhost:8080`

## إضافة محتوى

### مفردة لهجية

أضف عنصرًا إلى `data/dialect.json`:

```json
{
  "id": "word-id",
  "word": "الكلمة",
  "meaning": "المعنى",
  "example": "جملة الشاهد.",
  "region": "عامة",
  "note": "ملاحظة اختيارية"
}
```

### مثل

أضف عنصرًا إلى `data/proverbs.json`:

```json
{
  "id": "proverb-id",
  "text": "نص المثل",
  "meaning": "شرح المعنى",
  "theme": "الموضوع"
}
```

### منطقة

أضف عنصرًا إلى `data/regions.json`:

```json
{
  "id": "region-id",
  "name": "اسم المنطقة",
  "capital": "المركز",
  "lat": 23.0,
  "lng": 57.0,
  "note": "توصيف موجز"
}
```

## النشر

موقع ثابت بلا خطوة بناء. ارفع الملفات إلى أي استضافة ملفات ثابتة
(GitHub Pages أو غيرها)، وتأكد من وجود `.nojekyll` عند النشر على GitHub Pages.
