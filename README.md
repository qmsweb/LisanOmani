# اللسان العماني — LisanOmani

منصة عربية متكاملة تعنى بدراسة **الظواهر الدلالية** في اللغة العربية: الترادف والتضاد، والكلمات الدخيلة، والحقول الدلالية، وأدوات تفاعلية للتعلم والاستكشاف.

موقع ثابت (Static Site) يعمل مباشرة في المتصفح دون خادم أو قاعدة بيانات، وجاهز للنشر على GitHub Pages.

## الموقع

- **الرابط:** https://qmsweb.github.io/LisanOmani/
- **المستودع:** https://github.com/qmsweb/LisanOmani

## حالة الإصدار

الموقع الآن **طبعة مراجعة غير مفهرسة**: يمنع الزحف عبر `robots.txt` ووسوم
`noindex` في كل صفحة، ولا يوجد ملف `sitemap.xml`. عند الإطلاق العلني تُزال
هذه القيود (انظر القسم الأخير في `DESIGN.md`).

## المزايا

- **الترادف والتضاد:** بحث في 110 مدخلات دلالية، مع دعم البحث داخل المرادفات والأضداد، وتطبيع الهمزات والتاء المربوطة والتشكيل.
- **الكلمات الدخيلة:** معجم من 50 كلمة، يعرض الأصل الأجنبي والكلمة الأصلية والمعنى، مع تصفية بحسب اللغة الأصلية.
- **الحقول الدلالية:** خمس خرائط مفاهيمية تفاعلية (الصدق، العلم، الثورة، الفرح، الطبيعة) مبنية بمكتبة D3.js، مع تعريف كل عقدة وأمثلتها، وإمكانية تصدير الخريطة صورةً أو بيانات JSON.
- **الكلمات المتقاطعة:** لعبة تعليمية تربط تخمين الكلمة بمرادفاتها وأضدادها وخصائص حرفها الأول الصوتية.
- **البحث الشامل:** محرك بحث واحد يعبر كل المصادر ويصنّف النتائج بروابط مباشرة إلى الأداة المناسبة.
- **واجهة بسيطة:** شريط علوي رفيع، سطر تعريفي، شبكة بطاقات بيضاء، وتذييل واحد؛ لون توكيد أخضر، وخط واحد (IBM Plex Sans Arabic). موثّقة في `DESIGN.md`.
- **تجربة موحّدة:** ترويسة وتذييل مشتركان، تصميم متجاوب، دعم كامل للعربية (RTL)، ومراعاة إمكانات الوصول وتفضيل تقليل الحركة.

## تشغيل الموقع محليًا

يكفي فتح `index.html` في المتصفح، لكن بعض المتصفحات تمنع تحميل ملفات JSON عبر بروتوكول `file://`. لذا يُفضّل تشغيل خادم محلي بسيط:

```bash
# باستخدام Node.js
npx serve .

# أو باستخدام Python
python -m http.server 8080
```

ثم افتح: `http://localhost:8080`

## إضافة محتوى

### مدخل ترادف وتضاد

أضف مدخلًا في `data/semanticData.json`:

```json
"الكلمة": {
  "synonym": ["مرادف1", "مرادف2"],
  "antonym": ["ضد1", "ضد2"]
}
```

### كلمة دخيلة

أضف عنصرًا إلى مصفوفة `data/loan.json`:

```json
{
  "arabic": "الكلمة",
  "origin": "اللغة الأصلية",
  "original": "الكلمة الأصلية",
  "meaning": "المعنى أو الاستعمال"
}
```

### حقل دلالي

1. أضف ملفًا إلى `data/hqool/` بالبنية التالية:

```json
{
  "fields": [{
    "id": "field-id",
    "title": "اسم الحقل",
    "description": "وصف الحقل",
    "nodes": [
      { "id": "1", "label": "المفهوم", "type": "core", "size": 22, "definition": "تعريف", "examples": ["مثال"] }
    ],
    "links": [
      { "source": "1", "target": "2", "weight": 2 }
    ]
  }]
}
```

2. سجّله في `data/fields.json`:

```json
{ "id": "field-id", "title": "اسم الحقل", "file": "data/hqool/6.json", "summary": "وصف موجز" }
```

أنواع العقد المدعومة: `core` (مفهوم مركزي)، `event` (حدث)، `actor` (فاعل)، `method` (طريقة)، `emotion` (عاطفة)، `result` (نتيجة).

## النشر على GitHub Pages

1. ارفع المشروع إلى المستودع.
2. من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. احفظ الإعدادات، وسيُنشر الموقع على `https://<username>.github.io/LisanOmani/`.

جميع المسارات نسبية، وملف `.nojekyll` يضمن نشر الملفات والمجلدات التي تبدأ بشرطة سفلية.
